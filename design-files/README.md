# Native design files

The original exports are in [assets](../assets/) once uploaded. Editable design files were not provided for this repository snapshot. Add your actual project files here, after checking contributor permissions and removing personal information:

- `easyeda/`: native schematic and PCB design exports.
- `proteus/`: simulation project and required libraries (only if redistributable).
- `manufacturing/`: reviewed Gerber/drill files, if applicable.
- `waveforms/`: actual simulation or measured captures with labels.

Do not rename image files to CAD extensions or describe a 3D rendering as a fabricated board. This directory intentionally contains instructions only.
